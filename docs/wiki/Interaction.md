# 操作与动画

适用：`0.1.0-SNAPSHOT`，业务协议 v7，未发布。

2026-10-14 源码增加物品悬停提示：指向内景物品、穿戴容器、手持物品或盔甲时，显示原版 tooltip 及注册的简介。仅最上层可见物品参与命中；拖放或拖动相机期间不遮挡落点。简介注册方式见[物品扩展](Extension-Guide.md)。

1. **I → 功能 → 库存 / 3D 背包** 直接在工作台显示可操作的玩家模型。**B** 恢复已存在的工作台背包窗口；尚未创建时打开独立装备预览。两种入口共用下述操作。人物取景随可用窗口尺寸调整，开关容器不自动平移或拉近。右键拖动人物区域，或左键拖动未穿装备的身体区域，旋转人物和身上的容器；水平、垂直拖动均采用反转方向。
2. 左键拖动身上的草包沿腰部调整位置，角度连续变化，默认最多 2 件腰挂；背篓只能拖到胸前或背后，各一个位置。旋转人物以露出另一侧后再拖放。装备位置由服务器确认并保存。
3. 指向容器模型高亮轮廓，点击并松开后开盖，再显示内景。左拖容器模型搬动物品，右拖人物旋转视角；超过拖动阈值后松开不会误开容器。
4. 每个容器只有一个三维内景和独立相机，下方不显示全景、分层、存取或旋转按钮。顶部为细标题、**−** 和 **×**，没有厚页签；拖动细标题移动窗口。**−** 最小化到下方名称入口，点击恢复；**×** 合盖并关闭该窗口。
5. 内景上方新增**双滑块横向范围条**：下方手柄控制最低可见层，上方手柄控制最高可见层，向左右拖动并吸附整层。右侧数字从 1 开始，例如 `2–2` 表示只看第二层；两个滑块不能交叉，至少渲染一层。默认显示全部格层，各窗口独立，最小化与恢复保留范围。改变范围不会移动相机、物品或触发转移。
6. 左键拖动内景空白处或右键拖动内景都可旋转整个三维场景，方向与人物拖动一致；视口内滚轮缩放。即使已选中物品，拖动空白处也不会提交转移。范围条同时裁剪网格、物品模型、数量与鼠标命中，跨层物品保留可见部分，隐藏层不参与点击。携带物品时沿光标投影选择最近的合法空位；手动放置的完整占格必须位于可见范围，较高物品需先扩大范围。真实碰撞仍检查全部库存，切片不会空出原本已占用的格子。
7. **已占用格持续高亮外轮廓**。按面相邻的占用格连成一片，不显示共面内部亮线；跨物品实例同样连接，凹角与空洞边缘保留。未占用格保持暗色参考网格，悬停、选中与非法落点仍有各自提示。
8. 左键拖动物品到同一窗口或另一窗口的具体格位；也可点击选中后再点击目标格。候选三维模型和占格线框随光标显示，非法落点使用主题的错误落点颜色，松开不提交。
9. **R** 绕容器 Y 轴左右旋转 90°，**T** 绕 X 轴上下旋转 90°；按住 **Shift** 反向。只在背包界面选中或拖动物品时读取，不注册全局旋转键，也不出现在原版控制设置里。通过 `config/bs3d/config.toml` 的 `[controls]` 表修改，按 **F3+T** 重读后帮助说明跟随新绑定；打开背包的 **B** 仍在原版控制设置中改键。
10. 将角色左手或右手中的物品拖到容器内景的具体格位存入；将内景物品拖到角色某只手上取出；两只手可直接互相拖放。手掌悬停显示轮廓，命中位置跟随骨架、视角和惯用手设置。每次转移整个真实 ItemStack；目标手为空时接收物品，同种物品仅在能完整叠放时合并，否则拒绝并保留原库存，不自动换手或塞入其他背包槽。Shift 点击内景物品取回原版库存；Shift 点击手持或原版槽位物品进入有空位的随身容器，腰挂优先于胸背，保留朝向，不受显示切片限制。

11. 头盔、胸甲、护腿、靴子直接在角色对应部位抓取，拖到手掌或内景取下；反向拖到对应身体部位穿上。目标装备槽必须为空且类型匹配，生存模式不能取下绑定诅咒装备。
12. 草包和背篓本身也是物品，可拖到手里或其他容器的内景。内容随包保存；右键手中的容器物品或内景里的子容器，打开它的独立内景窗口。将物品拖回适合的身体位置即可装备。容器不能放入自身或子孙。收纳箱内部为 5×3×2；草包外部 2×2×2 可放入，背篓外部 3×3×4 在任何朝向均放不下。
13. 在世界中手持草包、背篓或收纳箱，按住 **Shift＋右键** 点击地面上表面放下，播放放置音效。需要空位和完整支撑；放下的是原物品，创造模式也会从手中移走它。
14. **右键地面背包**打开相同的三维内景，可与自己的手、装备及其他容器转移物品。打开 B／I 场景也会发现附近可访问的地面背包，模型初始合盖，可直接投放。离开 5 方块交互范围、被墙遮挡或退出整个页面后，访问结束；同一地面背包不能同时被两位玩家操作。
15. 先退出背包页面，再用**空手 Shift＋右键**收回地面背包，全部内容与原身份保留。直接挖掘不会取回背包。放置、收回整包和内部存取都即时完成。地面背包在页内合盖后保留模型，同样可作为自动放置落点。

操作文字集中在右上角圆形 **i** 按钮，点击展开帮助；面板中的按键名称跟随绑定更新，小窗口中可滚动阅读。帮助打开期间拦截背后的点击、拖动和旋转按键；再次点击 **i**、点击面板外或按 ESC 关闭帮助。B 和原版背包退出键直接退出背包。正常页面保留窗口控制，不常驻操作说明；错误与操作结果在帮助面板的“当前状态”中查看。

旋转键配置示例（放在 `version = 1` 之后、首个 `[[models]]` 之前）：

```toml
[controls]
rotate_yaw = "key.keyboard.r"
rotate_pitch = "key.keyboard.t"
```

支持原版键名，例如 `key.keyboard.y`、`key.keyboard.page.up` 或鼠标侧键 `key.mouse.4`。旧配置省略该表或某个字段时采用默认 R/T，不迁移原版 `options.txt` 中旧的旋转绑定。字段拼错、键名无效或类型错误时，日志报告配置错误，旋转键恢复默认；本地模型导入也遵循[配置整体拒绝规则](Model-Resources.md)。

人物预览与每个内景各自清理绘制前后的深度缓存，保留颜色和模型内部遮挡，避免模型旋转时被界面底板裁掉，或拖动窗口后用残留深度遮住后续控件。

容器开合读取已登记 `.bbmodel` 的动画及其时长；没有动画的静态模型直接打开内景，不额外等待。开启、关闭、地面放置、收回和触碰声音可在 `config/bs3d/config.toml` 配置，见[模型资源导入](Model-Resources.md)。恢复已打开的最小化窗口不会重新播放开启声。

旋转先改变待放置姿态，松开到目标格才提交即时转移；旋转不缩小体积。已保存物品保留服务器记录的原始尺寸，数据包重载不会重新解释旧物品尺寸。数量仍是 ItemStack 数量。

拖放在服务端收到请求的同一 tick 内校验、提交并回执，不锁角色行走。回执前来源显示半透明占位；拒绝后原位恢复，并在帮助面板“当前状态”说明原因。成功只播放一次材质完成声。

将任意来源的物品拖到身上容器模型，开盖或合盖都自动寻找完整容量内的空位。模型悬停使用主题“可落”颜色并显示容器名；拖到内景具体格位仍是手动放置。放不下保留原位，例如“背篓里放不下”。B 独立页、I 工作台共用该场景；E 玩家页及原版容器页由 Vanilla 附属接入。

ESC、B、原版背包退出键合盖退出；Ctrl+W 或窗口 × 关闭当前容器。已发送请求不因关窗反向撤销。I 页面退出释放地面访问，再次进入需重新打开内景。拖到外框之外不发请求。

服务端仍拒绝死亡、旁观、骑乘、失效来源、过期修订和超距地面访问。所有窗口共用同一权威修订号。

装备后的草包、背篓同时显示在游戏世界的玩家身上，关闭 UI 后仍然可见。按 F5 切换第三人称可查看自身装备，附近玩家也能看到；腰角和胸背位置与 UI 一致，并随躯干动作变化。卸下或收纳进另一容器后，穿戴外观随服务端提交结果更新。隐身和旁观者隐藏容器外观，世界中的包盖保持关闭。参阅[通信契约](Protocol.md)与[扩展说明](Extension-Guide.md)。
