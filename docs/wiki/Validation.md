## 复验

```sh
./gradlew -Dorg.gradle.java.home="/path/to/jdk17" \
  -PframeworkDir="/path/to/framework" test build
python3 scripts/wiki.py check
python3 scripts/smoke.py --framework-dir "/path/to/framework" \
  --java-home "/path/to/jdk17"
```

smoke 在 `build/smoke/<run-id>` 创建隔离世界，生成测试物品并主动模拟输入，验收后退出。Linux 默认使用 Xvfb；显式 `--show-window` 才显示自动操作，Windows 自动验收也需要此参数。它不是手动体验入口，正常生产 JAR 打开容器只播放开盖动画，不自动转移。

2026-10-13 已按用户要求使用含世界外观和地面背包的 v6 生产 JAR 启动 Windows Native 客户端与专用服务器，并核对两端 SHA-256。更新前正常停止并备份原世界、玩家库存和旧 JAR；服务端日志确认玩家进入原测试世界，客户端完成加载。运行环境为 Windows Java 17、Minecraft 1.20.1、Fabric 0.16.10。范围条和连接轮廓版本后续已更新到该手动实例并成功进入原测试世界。本次 bbmodel 导入版本未更新或重启该 WN 实例。玩家保存格式 1/2 自动迁移至 3，详见[通信和持久化](Protocol.md)。

尚未验证第三方资源包与自定义物品渲染器组合；单机内置服务器已于 2026-10-14 适配并验证，见下方记录。多人同时编辑同一容器尚未实现。地面背包没有个人所有权限制，附近玩家可依次使用。API 未冻结，详见[接入说明](Getting-Started.md)。
