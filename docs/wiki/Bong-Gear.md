# Bong 收纳装备

2026-11-03：原有 9 件之外增加枯藤腰带，共 10 件真实容器物品，沿用 BS3D 的即时转移、嵌套、穿戴、地面放置与保存逻辑。客户端和服务端须同时安装本轮版本。业务协议为 v8，玩家保存格式为 4，可读取原格式 3 的容器存档。

## 获取与容量

生存里在工作台用原版材料合成，背包里第一次进了主材料时配方书解锁，见下文「合成」；也可在创造模式“背包与收纳”物品栏（`bs3d:containers`）取得，或使用 `/give @s bs3d:gu_jia_bei_lou` 等原版命令。三个背负件只允许背后挂点，皮囊胸挂只允许胸前挂点；其余六件共用腰部挂点：五件挂包计入玩家腰部数量上限（默认两件）；枯藤腰带不占名额，每人最多系一条，系上腰带后仍能挂两个挂包。从手中拖到身体对应位置穿戴，点击模型进入内景。五件挂包沿腰环选角度；枯藤腰带是整圈腰带，拖到躯干任意处都系在腰上，不能调角度。

## 模型与加载

模型来源为 [Bong](https://github.com/Kizunad/Bong) 的 `c01576513e451490bd73df12513227bb8637222b`，对应 [PR #2419](https://github.com/Kizunad/Bong/pull/2419) 与 [PR #2420](https://github.com/Kizunad/Bong/pull/2420)。源文件位于 `modelScript/gear/<id>/*_tex.bbmodel`，包含逐面 UV 与内嵌 PNG。

`server/src/main/resources/bs3d/bong-gear/items.txtpb` 集中登记物品、容量、挂点与模型路径，common 服务端 JAR 同时用于客户端安装。模型通过已有的[物品清单](Item-Registry.md)自动加载，已有 `config/bs3d/config.toml` 不必修改。玩家登记同一模型 ID 时仍优先使用本地模型，F3+T 重载规则见[模型资源](Model-Resources.md)。

原模型按整个人体坐标建模。本次转换抵消 BS3D 的挂载缩放、换算人体原点并调整胸背朝向，保留立方体旋转、逐面 UV 和骨骼层级。三件背负装备与胸挂保留整体挂具；五件腰挂装备剥离人体固定腰带或肩带，保留包体和局部挂环，使它们能沿腰环移动。水囊另外移除肩带上的两枚远端环。枯藤腰带不剥离任何部分，也不缩放，只把身体中心移到模型中心。

| 导入方式 | 适用 | 导入缩放 | 穿戴时每模型像素 | 物品栏与手持 |
|---|---|---|---|---|
| `back`、`front` | 三件背负、皮囊胸挂 | ÷ 0.8 | 0.8 / 16 格 | 0.64 |
| `waist` | 五件挂包 | ÷ 0.5 | 0.5 / 16 格 | 0.4 |
| `belt` | 枯藤腰带 | 1:1 | 1 / 16 格 | 0.8；手持与掉落盘起 |

导入缩放与穿戴缩放相乘为 1，身上和地面都是原尺寸；物品栏与手持统一画成原模型的 0.8 倍。整圈腰带 1:1 套在手上比躯干还宽、掉在地上占满一格，所以手持和掉落物另画成盘起的一小盘：水平 0.4 倍、高度 0.2 倍、前倾 20 度露出盘面；物品栏仍画整圈。

模型里的草药、矿石、卷铺盖、陶罐、骨币等是固定外观装饰，不是库存实例，不会自动生成物品；实际内景只显示服务器快照中的真实 ItemStack。十份源模型均没有开合动画，点击后直接打开内景。尚未制作新的开合动画或专属声音，使用现有默认声音。

## 更新源文件

转换脚本固定源版本并校验十份原文件的 Git blob SHA-1。它生成模型、物品清单、26.2 特殊物品定义、原版物品展示变换、中英文语言键及 `sources.json` 来源记录：

```sh
python3 "scripts/import_bong_gear.py" "/path/to/Bong"
python3 "scripts/import_bong_gear.py" "/path/to/Bong" --check
```

升级源模型时先核对脚本中的源版本、SHA、挂带剥离与坐标适配。不要把新文件直接覆盖到生成目录而跳过核验。验证范围与本次环境限制见[验证状态](Validation.md)。
